Case study · Choosing the model

How I picked the AI for the commission assistant

I didn't start with Claude. I tried three setups against the same hard questions and kept the one that answered them.

  1. Tried first

    Microsoft 365 Copilot

    File and prompt caps meant it couldn't read across years of transcripts at once.

  2. Tried second

    Copilot Studio + Azure vector search

    Power Automate and scripts got more data in, but vector search was hard to work with, and complex questions needed yet another model added.

  3. Chosen

    Claude + MCP connectors

    Connected straight to the city's shared folders. Better answers on the complicated questions, and more control over how it cites sources.

Approach

How I bring AI into an organization

Five years running projects inside city government shaped how I do this. The model is the easy part.

Step 1

Start with the question

I sit with department heads and find the question people keep digging for, before I pick any tool.

Step 2

Test more than one model

I run real questions through more than one platform and keep the one that answers them, as with the commission assistant.

Step 3

Keep the data safe

The AI reaches data through connectors and verified servers. It never gets a database login.

Step 4

Show sources, then train

Answers cite the video timestamp or code section. Then I train staff until they trust it and use it.
